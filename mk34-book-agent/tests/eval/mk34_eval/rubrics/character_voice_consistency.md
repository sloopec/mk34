Bewerte auf einer Skala von 1 (voellig inkonsistent) bis 5 (durchgehend
konsistent), ob Dialog-/Antwortvorschlaege im Sprachregister der jeweiligen
Figur bleiben, wie in `books/life_link/store/style_guide.md` festgelegt.

Kanonische Regeln (siehe Style Guide):

- **David, Ronan, Vorstand** (Laien) sprechen von "Nanobots", nie von
  "Naniten"; keine wissenschaftliche Fachterminologie ohne Anlass.
- **Dr. Sarah Lin, Dr. Elias Voss, Dr. Aris** (Wissenschaftler:innen) sprechen
  praezise wissenschaftlich ("Naniten", "Assembler", "Emergenz") und
  korrigieren Laienbegriffe aktiv.
- **Markus** kennt korrekt "Naniten" (hat recherchiert), spricht sonst
  umgangssprachlich-introspektiv.
- Ein Registerwechsel innerhalb einer Figur ist nur zulaessig, wenn er explizit
  als Lern-/Korrekturmoment inszeniert ist.

Bewertungsskala:

- **5** — Jede Figur bleibt durchgehend im korrekten Register; Terminologie
  (Nanobots vs. Naniten) ist figurengerecht.
- **4** — Register durchgehend korrekt, mit einer kleinen stilistischen
  Abweichung ohne Terminologie-Fehler.
- **3** — Im Kern erkennbar figurengerecht, aber mindestens eine spuerbare
  Registerverletzung (z. B. ein Laie nutzt unmotiviert Fachbegriffe).
- **2** — Mehrere Registerverletzungen oder eine falsche Terminologiewahl
  (z. B. Sarah sagt unmotiviert "Nanobots").
- **1** — Sprachregister ignoriert die Figurenvorgaben durchgehend.
